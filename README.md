# 片刻 · VideoCut

一个小巧的 Windows 视频裁剪工具。双击 `VideoCut.exe` 或 `run.cmd` 运行；修改代码后运行 `build.cmd` 重新编译。

界面预览见 `ui-preview.png`。运行 `smoke.cmd` 可用测试视频检查预览、标记撤销、流复制和重新编码。

## 使用

1. 点击视频下方的“打开视频”或拖入视频，在时间轴拖动定位，可选择预览倍速。打开对话框支持多选，或一次拖入多个视频；这些视频会按列表顺序显示在“裁剪片段”区域，可上移、下移或移除。
2. 视频下方播放控件的中间有两个时间框。直接输入时间后点击旁边的 **Z 起点**、**X 终点**，或在时间轴定位后直接点击按钮使用当前播放位置。输入框内按回车也可确认对应标记。有效片段会自动加入下方列表，可逐条编辑、删除或上下移动调整输出顺序。
3. 继续标记多个片段，选择输出方式和文件夹。点击 **转换** 会将每条记录单独输出一个文件；点击 **合并转换** 会按列表顺序裁剪并拼接成一个视频（至少需要两条记录）。载入多个视频后，点击 **合并视频** 会将完整视频按列表顺序拼接，输出文件名为第一条视频名加“_合并”。

快捷键：空格播放或暂停；**V** 后退 10 秒；**B** 前进 10 秒；**Z** 设置起点；**X** 设置终点；**C** 撤销最近一次时间操作。片段生成后，再按 X 会修改最近一条记录的终点；按 C 可恢复上一个终点。此时按 Z 会开始新片段。刚生成片段后按 C 会撤销终点并移除该片段，再按一次 C 会撤销起点。

默认“原视频流复制”不重新编码，速度快且画质不变，但裁剪点受关键帧限制，成品可能略早于所选起点。需要精确起点时选择“重新编码 · H.264”。倍速仅作用于预览。

输出文件夹、预览倍速和输出方式会自动保存到当前 Windows 用户配置中，下次启动时自动恢复。

## 运行要求

- Windows 和 .NET Framework 4.8（Windows 10/11 通常已具备）。
- 转换需要 FFmpeg。程序优先使用同目录下的 `ffmpeg.exe`，然后读取 `ffmpeg.path`，最后查找系统 PATH。界面可随时重新选择 FFmpeg。仓库中的 `ffmpeg.path` 指向此电脑上已安装的 FFmpeg；移动到其他电脑时请重新设置。

程序本体不捆绑大型运行时或 FFmpeg，保持体积小巧。预览使用 Windows 自带媒体组件，某些特殊编码的视频可能无法预览，也就无法在时间轴上标记片段。
